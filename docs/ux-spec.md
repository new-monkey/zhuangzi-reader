## 1. 目标与非目标

### 1.1 目标

1. **像读书，而不是像读网页**：一屏一页、篇章分明、翻页有方向感。
2. **把中文古籍的排印规矩做对**：竖排右起、标题独占栏位、简繁可切、标点与行距可调。
3. **零依赖、零网络**：一个 HTML 文件，双击即读；离线可用，不上传任何数据。
4. **手机可读**：单手可翻、字号不憋屈、不与系统手势打架。

### 1.2 非目标

- 不做批注 / 书签 / 笔记同步（无账号体系）。
- 不做多书库；本文件只服务《庄子》一部典籍（`texts/zhuangzi.txt`）。
- 不做 TTS 朗读、词典释义、译文对照。
- 不追求「无限列表」式的长文浏览；阅读模型固定为**分页**。

## 3. 设计原则

| 编号 | 原则 | 展开 | 落到设计上的约束 |
| --- | --- | --- | --- |
| UX-P-01 | 内容优先 | 阅读时只有字与纸，控件可退场 | 顶栏与页码条半透明、可点击区域互不遮挡正文；正文与页脚之间留 20px |
| UX-P-02 | 纸感与秩序 | 版心有边界、页有页边、篇有篇首 | 一屏一页；每篇必从新页开始；页边界永不切在字/栏中间 |
| UX-P-03 | 跟手可预测 | 拖动时内容跟随手指，松手落到明确的页 | 拖动中禁用过渡；松手阈值明确；越界回弹 |
| UX-P-04 | 方向一致 | 阅读方向决定翻页方向，横竖一致 | 下一页恒在当前页左侧（传统右起）；向右拖/滑 = 下一页 |
| UX-P-05 | 随时可退 | 任何面板都能一键关闭，任何状态都能回到阅读 | `Esc`/遮罩/关闭按钮三条退路 |
| UX-P-06 | 记忆优先 | 用户不必关心「我读到哪了」 | 位置、简繁、排版、主题全部持久化 |
| UX-P-07 | 无网络假设 | 断网、飞行模式、隐私窗口都要能用 | 无字体 CDN、无统计脚本、无外部请求 |

## 4. 信息架构

```
阅读页（唯一的页面）
├── 顶栏：目录 / 书名 / 当前篇 / 搜索 / 简繁 / 横竖 / 排版
├── 正文（分页）
│   └── 篇 → 段（篇首必另起一页）
├── 页码条：上一页 / 第 n / N 页 / 下一页
└── 面板（互斥，覆盖式）
    ├── 目录（内篇 7 / 外篇 15 / 杂篇 11，共 33 篇）
    ├── 搜索（输入 + 命中计数 + 上/下一处 + 结果列表）
    └── 排版（主题 / 字体 / 字号 / 行距 / 版心 / 段距 / 排列 / 字形）
```

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |
| UX-IA-01 | 任意篇从阅读页出发 ≤ 2 次操作可达（打开目录 → 点篇名） | MUST | ✅ |
| UX-IA-02 | 任意面板都可用「再次点击入口按钮 / `Esc` / 点遮罩」关闭 | MUST | ✅ |
| UX-IA-03 | 目录、搜索、排版三者互斥，同时只开一个 | MUST | ✅ |
| UX-IA-04 | 顶栏「当前篇」显示「篇名｜第 N」，随翻页实时更新 | SHOULD | ✅ |
| UX-IA-05 | 章节序号与分卷（卷一上 / 外篇 等）在目录与篇首同时可见 | SHOULD | ✅ |

## 5. 布局与栅格

### 5.1 全局框架

```
┌──────────────────────────────────────────── 顶栏 52px（固定）
│ 目录  莊子 南華經   当前篇｜第N     搜索 繁 竖排 Aa │
├────────────────────────────────────────────
│                                             ▲
│              版心（viewport）：              │ 页边距
│              一页的可见区域                  │ --pad-y
│              正文在其内部按列排布             ▼
│                                                页码条（浮于页脚留白）
└────────────────────────────────────────────
```

| 编号 | 需求 | 取值 / 行为 | 等级 | 状态 |
| --- | --- | --- | --- | --- |
| UX-LAY-01 | 顶栏高度固定，不随滚动位移 | 52px（手机 ≥ 48px 且不换行） | MUST | ✅ |
| UX-LAY-02 | 版心与屏幕之间留页边距 | 桌面 34×22px；手机 18×14px | MUST | ✅ |
| UX-LAY-03 | 正文与页码条不重叠 | 版心下边界再让出 20px | MUST | ✅ |
| UX-LAY-04 | 顶栏与页码条使用半透明背景 + 背景模糊，避免硬遮断 | — | SHOULD | ✅ |
| UX-LAY-05 | 页面只允许纵向窗口滚动＝0；正文由分页而非滚动推进 | `overflow: hidden` | MUST | ✅ |

### 5.2 版心与分页栅格

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |
| UX-GRID-01 | 页宽 = 「整数栏 × 栏距」：竖排一栏＝一行竖排文字；横排一栏＝一页 | MUST | ✅ |
| UX-GRID-02 | 栏距量化到 1/64px，并以后实测值定页宽，防止累计误差把页切在字中间 | MUST | ✅ |
| UX-GRID-03 | 页边界与栏边界严格对齐（误差 < 0.02 页） | MUST | ✅ |
| UX-GRID-04 | 横排版心宽度默认 36 字，可调 18–70 字；竖排由字号/每页栏数推导 | MUST | ✅ |
| UX-GRID-05 | 每篇强行起新页；篇题必在页首（横排用 `break-before: column`，竖排用空白块推页） | MUST | ✅ |
| UX-GRID-06 | 竖排篇题独占**两栏**，标题两侧不得被版心裁切（字号 14–36px 全覆盖） | MUST | ✅ |
| UX-GRID-07 | 单页至少容纳 6 行；不足时优先缩小页边距，仍不足则允许少于此值 | SHOULD | ⏳ |

### 5.3 断点与设备档

| 断点 | 触发条件 | 行为 |
| --- | --- | --- |
| 宽屏 | ≥ 900px | 面板为右侧抽屉（TOC 286px / 面板 340px），不加遮罩、不压暗正文 |
| 窄屏 | < 900px | 面板覆盖式：目录 80vw、搜索/排版 100vw，加 28% 遮罩，点击遮罩关闭 |
| 小屏 | ≤ 760px | 顶栏收紧（书名副标题隐藏、按钮内距变小）、版心页边距 18×14px |
| 极小屏 | ≤ 400px | 按钮内距进一步收紧，按钮文案保留不截断 |

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |
| UX-BP-01 | 上述断点行为与实现一致，无横向溢出 | MUST | ✅ |
| UX-BP-02 | 顶栏在 ≤ 400px 宽度下不换行、不遮挡最后一个按钮 | MUST | ⏳（需实测 iPhone SE 字号放大场景） |

### 5.4 安全区（刘海 / 圆角 / 手势条）

| 编号 | 需求 | 等级 | 状态 |

## 6. 阅读核心

### 6.1 分页模型

| 编号 | 需求 | 说明 | 等级 | 状态 |
| --- | --- | --- | --- | --- |
| UX-PAGE-01 | 一屏一页；翻页以整页为单位，不接受「滚动到任意位置」 | 横排同样分页 | MUST | ✅ |

| UX-PAGE-03 | 页序号从 1 开始显示「第 n / N 页」 | — | MUST | ✅ |

| UX-PAGE-05 | 竖排的「卷号」小字与篇名同栏，标题整体位于页首 | — | SHOULD | ✅ |

### 6.2 阅读位置与进度

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |
| UX-POS-01 | 关闭后重开回到上次位置（精确到页） | MUST | ✅ |
| UX-POS-02 | 切换简繁、字号、行距、版心、横竖后，仍停在同一段落所在页 | MUST | ✅ |
| UX-POS-03 | 顶部进度条表示全书进度（页数比） | SHOULD | ✅ |
| UX-POS-04 | 位置保存需等翻页动画结束后测量，避免记录到上一页 | MUST | ✅ |

### 6.3 翻页方向与动画

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |
| UX-FLIP-01 | 向右拖动/滑动 = 下一页；向左 = 上一页；横竖一致 | MUST | ✅ |
| UX-FLIP-02 | `←` = 下一页，`→` = 上一页（与右起书一致） | MUST | ✅ |

| UX-FLIP-05 | 越界拖动允许最多 35% 页宽的橡皮筋效果 | SHOULD | ✅ |
| UX-FLIP-06 | 系统开启「减弱动态效果」时，落页改为瞬时（无过渡） | MUST（无障碍） | ⏳ |

## 7. 交互规格

### 7.1 手势表

| 手势 | 行为 | 阈值 | 冲突处理 | 状态 |
| --- | --- | --- | --- | --- |
| 水平拖动（触摸/鼠标） | 跟手位移，松手落页 | > min(90px, 18% 页宽) 翻页，否则回弹 | 起手 8px 内判定主轴；纵向优先让给选中/滚动 | ✅ |
| 轻点左侧 32% | 下一页 | — | 有文字选区时不响应 | ✅ |
| 轻点右侧 32% | 上一页 | — | 同上 | ✅ |
| 轻点中间 36% | 不翻页（可选：切换沉浸模式） | — | — | ✅（当前无动作）/ 💡 |
| 滚轮 / 触控板纵向 | 下 = 下一页，上 = 上一页 | Δ ≥ 3px，180ms 节流 | 面板打开时不响应 | ✅ |
| 双指缩放 | 交给浏览器（`touch-action: pinch-zoom`） | — | 不拦截 | ✅ |
| 长按 | 交给系统（选择/放大镜） | — | 正文不绑定长按手势 | ✅ |
| 双击 | 不缩放、不翻页（MAY：切换沉浸模式） | — | — | 💡 |
| 屏幕边缘水平滑动 | **让给系统**（iOS 返回、Android 手势导航） | 距左右边缘 ≤ 20px 不翻页 | 需要新增保护 | ⏳ |

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |
| UX-GEST-01 | 手势在横排与竖排语义一致（向右 = 下一页） | MUST | ✅ |
| UX-GEST-02 | 拖动过程中内容位置必须与手指位移 1:1 对应 | MUST | ✅ |
| UX-GEST-03 | 拖动过程中不得选中文本、不得触发浏览器原生拖拽 | MUST | ✅ |
| UX-GEST-04 | 非拖动状态下正文可正常选中复制 | MUST | ✅ |
| UX-GEST-05 | 距屏幕左右边缘 20px 内的水平拖动不翻页 | MUST | ⏳ |
| UX-GEST-06 | 面板打开时，正文区手势（拖动/点击/滚轮）一律不翻页 | MUST | ✅ |

### 7.2 触控目标

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |
| UX-TOUCH-01 | 所有可点元素在触摸设备上热区 ≥ 44×44 CSS px（视觉可小，热区需撑满） | MUST | ⏳（当前 28–32px） |

## 附：术语

| 术语 | 含义 |
| --- | --- |
| 版心（viewport）| 一页的可见区域，正文在其中按列排布并被裁切到页边界 |
| 栏（column）| 竖排：一列文字（行）；横排：一页的文字块 |
| 页宽 / 栏距 | 页宽 = 整数栏 × 栏距；栏距 = 字号 × 行距倍数 |
| 右起 | 下一页位于当前页左侧（传统中文书页翻动方向） |
| 篇首对齐 | 每篇第一栏恰好落在页边界上 |
