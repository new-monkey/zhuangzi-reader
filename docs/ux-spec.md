## 1. 目标与非目标

### 1.1 目标

1. **像读书，而不是像读网页**：一屏一页、篇章分明、翻页有方向感。
2. **把中文古籍的排印规矩做对**：竖排右起、标题独占栏位、简繁可切、标点与行距可调。
3. **零依赖、零网络**：一个 HTML 文件，双击即读；离线可用，不上传任何数据。
4. **手机可读**：单手可翻、字号不憋屈、不与系统手势打架、能进入沉浸阅读。

### 1.2 非目标

- 不做批注 / 书签 / 笔记同步（无账号体系）。
- 不做多书库；本文件只服务《庄子》一部典籍（`texts/zhuangzi.txt`）。
- 不做 TTS 朗读、词典释义、译文对照。
- 不采用「无限滚动 + 自由滚动」的阅读模型；**阅读模型固定为分页**。

## 3. 设计原则

| 编号 | 原则 | 展开 | 落到设计上的约束 |
| --- | --- | --- | --- |
| UX-P-01 | 内容优先 | 阅读时只有字与纸 | **正文占满版心**；页码/进度/按钮全部是浮层，不参与排版（§5.1） |
| UX-P-02 | 纸感与秩序 | 版心有边界、页有页边、篇有篇首 | 一屏一页；每篇必从新页开始；页边界永不切在字/栏中间 |
| UX-P-03 | 跟手可预测 | 拖动时内容跟随手指，松手落到明确的页 | 拖动中禁用过渡；松手阈值明确；越界回弹 |
| UX-P-04 | 方向一致（**v1.1 修正**） | 翻页方向 = 该排版的阅读推进方向；进度与方向键同向 | 横排：内容向左走 = 下一页；竖排：内容向右走 = 下一页（§6.3） |
| UX-P-05 | 随时可退 | 任何状态都能回到阅读、任何浮层都能唤出/关闭 | `Esc`/遮罩/关闭按钮三条退路；沉浸模式有固定唤出手势 |
| UX-P-06 | 记忆优先 | 用户不必关心「我读到哪了」 | 位置、简繁、排版、主题、沉浸状态全部持久化 |
| UX-P-07 | 无网络假设 | 断网、飞行模式、隐私窗口都要能用 | 无字体 CDN、无统计脚本、无外部请求 |
| UX-P-08 | 屏尽其用（**新增**） | 小屏不接受「常驻控件吃掉正文」 | 常驻 UI 面积 ≤ 56px 高度（顶栏）；翻页控件默认不存在 |

## 4. 信息架构

```
阅读页（唯一页面）
├── 顶栏（沉浸模式下可隐藏）：目录 / 书名 / 当前篇 / 搜索 / 简繁 / 横竖 / 排版 / 沉浸
├── 正文（分页，占满版心）
│   └── 篇 → 段（篇首必另起一页）
├── 浮层（不占排版空间，交互后出现、静置淡出）
│   ├── 页码「第 n / N 页」+ 细进度条
│   └──（可选）翻页提示箭头
└── 面板（互斥，覆盖式）
    ├── 目录（内篇 7 / 外篇 15 / 杂篇 11，共 33 篇）
    ├── 搜索（输入 + 命中计数 + 上/下一处 + 结果列表）
    └── 排版（主题/字体/字号/行距/版心/段距/排列/字形/沉浸）
```

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |
| UX-IA-01 | 任意篇从阅读页 ≤ 2 次操作可达（打开目录 → 点篇名） | MUST | ✅ |
| UX-IA-02 | 任意面板可用「再次点击入口 / `Esc` / 点遮罩」关闭 | MUST | ✅ |
| UX-IA-03 | 目录、搜索、排版三者互斥 | MUST | ✅ |
| UX-IA-04 | 顶栏「当前篇」显示「篇名｜第 N」，随翻页/跳转更新 | SHOULD | ✅ |
| UX-IA-05 | 章节序号与分卷在目录与篇首同时可见 | SHOULD | ✅ |
| UX-IA-06 | 沉浸模式状态属于「阅读状态」，刷新后保持 | SHOULD | ⏳ |
| UX-IA-07 | 页码与进度属于**浮层信息**，不占据正文空间 | MUST | ⏳ |

## 5. 布局与栅格

### 5.1 全局框架（v1.1：控件浮层化）

```
┌──────────────────────────────────────────── 顶栏 52px（固定，可隐藏）
│ 目录  莊子 南華經   当前篇｜第N     搜索 繁 竖排 Aa  ⛶ │
├────────────────────────────────────────────
│                                             ▲
│            版心 = 一页的可见区域              │ 页边距（极小，≥14px 安全值）
│            正文按列排布，铺满版心              │
│                                             ▼
│        ┌────────── 浮层（不占位）──────────┐
│        │  ◇ 第 12 / 84 页  ──────── 进度    │
│        └──────────────────────────────────┘
└────────────────────────────────────────────
```

## 6. 阅读核心

### 6.1 分页模型与页序（**v1.1 明确页序**）

| 排版 | 文字阅读方向 | 页序（第 1 页在哪、第 2 页在哪个方向） | 推进时内容移动方向 |
| --- | --- | --- | --- |
| 横排 | 行内左 → 右；行间上 → 下 | 第 1 页在最左上，**后续页在右侧**，页序左→右 | 内容**向左**整体位移 |
| 竖排 | 行内上 → 下；行间右 → 左 | 第 1 页在最右上，**后续页在左侧**，页序右→左 | 内容**向右**整体位移 |

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |
| UX-PAGE-01 | 一屏一页；翻页以整页为单位 | MUST | ✅ |
| UX-PAGE-02 | 页序与推进方向严格按上表（横排页序左→右，竖排页序右→左） | MUST | ⏳（竖排 ✅ / 横排 ⏳，当前横排也是右起） |
| UX-PAGE-03 | 页码「第 n / N 页」，从 1 开始 | MUST | ✅ |
| UX-PAGE-04 | 首/末页继续翻页时无操作 + 浮层轻微反馈；按钮不存在，故不涉及置灰 | MUST | ⏳（反馈）/ ✅（无按钮阻塞） |
| UX-PAGE-05 | 竖排「卷号」小字与篇名同栏，整体位于页首 | SHOULD | ✅ |

| 编号 | 需求 | 等级 | 状态 |
| --- | --- | --- | --- |

| UX-POS-02 | 切换简繁、字号、行距、版心、横竖后仍停在同一段落所在页 | MUST | ✅ |
| UX-POS-03 | 进度显示的方向与页序一致：**横排进度条自左向右增长，竖排自右向左增长** | MUST | ⏳（当前均为左→右） |
| UX-POS-04 | 位置在翻页动画结束后测量并保存 | MUST | ✅ |

### 6.3 翻页方向、手势与动画（**v1.1 重写**）

| 操作 | 横排（页序左→右） | 竖排（页序右→左） |
| --- | --- | --- |
| 手势/拖动 | **向左拖 = 下一页**；向右拖 = 上一页 | **向右拖 = 下一页**；向左拖 = 上一页 |
| 点击区域 | 右侧 1/3 = 下一页；左侧 1/3 = 上一页 | 左侧 1/3 = 下一页；右侧 1/3 = 上一页 |
| 方向键 | `→` = 下一页；`←` = 上一页 | `←` = 下一页；`→` = 上一页 |
| 触控板横滑 | 向左滑 = 下一页 | 向右滑 = 下一页 |
| 滚轮/双指纵向 | 向下 = 下一页（两种排版一致） | 向下 = 下一页 |
| 翻页动画 | 内容整体左移一页宽 | 内容整体右移一页宽 |
| 进度条 | 自左向右增长 | 自右向左增长 |

一句话记忆：**「朝阅读推进的方向推走当前页」就是下一页；横竖各自如此。**

| --- | --- | --- | --- |
| UX-FLIP-01 | 手势方向严格按 §6.3 表格，横竖不同 | MUST | ⏳（当前两种排版都是「右拖=下一页」） |
| UX-FLIP-02 | 方向键方向严格按 §6.3 表格，横竖不同 | MUST | ⏳（当前两种排版都是 `←`=下一页） |

| UX-FLIP-05 | 拖动位移超过「页宽 18% 或 90px，取小值」即翻页，否则回弹 | MUST | ✅ |
| UX-FLIP-06 | 越界拖动允许最多 35% 页宽的橡皮筋 | SHOULD | ✅ |
| UX-FLIP-07 | 翻页动画的运动方向必须与手势方向一致（同向跟随），不得往复 | MUST | ⏳（随 FLIP-01 一并修正） |
| UX-FLIP-08 | 系统「减弱动态效果」开启时，落页改为瞬时 | MUST | ⏳ |
| UX-FLIP-09 | 切换横竖后，同一段落仍在当前页（不得跳页） | MUST | ✅ |

### 9.9 沉浸式阅读与浏览器 UI（**新增，重点**）

小屏设备上「顶栏 + 地址栏 + 系统状态栏」会吃掉 100–170px。规范要求提供**沉浸式阅读**，并明确各平台可行的实现路径（因为网页无法在所有平台上直接控制系统 UI）。

## 附：术语

| 术语 | 含义 |
| --- | --- |
| 版心（viewport） | 一页的可见区域，正文在其中按列排布并被裁切到页边界 |
| 栏（column） | 竖排：一列文字（行）；横排：一页的文字块 |
| 页宽 / 栏距 | 页宽 = 整数栏 × 栏距；栏距 = 字号 × 行距倍数 |
| 页序 | 第 1 页在画面中的位置与后续页的方向：横排左→右，竖排右→左 |
| 翻页方向 | 推进到下一页时内容的移动方向：横排向左，竖排向右 |
| 浮层（overlay） | 覆盖在正文之上、不参与排版的可视信息（页码、进度、沉浸提示） |
| 沉浸模式 | 隐藏应用顶栏与浮层（并尽量隐藏浏览器 UI）的纯阅读状态 |
