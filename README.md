# 庄子 · 单页阅读器

把《庄子》（南华经）全文编译成**一个自包含的 HTML 文件**——双击即读，离线可用，无外部依赖、无网络请求。

面向中文古籍的阅读体验：可切换横排与竖排（传统右起翻页）、简繁显示、字体与版式，并提供目录导航与全文检索。

```
make build     # → dist/zhuangzi.html （约 520 KB）
```

> 语料为公有领域典籍；正文、脚本、样式全部内嵌在同一个 HTML 里，没有任何 `<script src>`、`<link href>` 或字体 CDN。

## 功能

| | |
| --- | --- |
| **目录导航** | 按 内篇 / 外篇 / 杂篇 分组共 33 篇；当前篇自动高亮并跟随滚动，点击即跳 |
| **全文搜索** | `Ctrl+F` / `/`：实时命中计数、上一处 / 下一处、结果列表（篇章 + 上下文）点击直达；命中处高亮 |
| **简体 / 繁体** | 一键切换（`T`）。繁体走 OpenCC `s2tw` 再做文言文校正；切换后保持阅读位置 |
| **横排 / 竖排** | 两种排版都是**按页阅读**，且传统右起：篇名总在页首。「向右拖动/滑动」= 下一页（下一页在左侧），`←` = 下一页、`→` = 上一页；也支持点击左右区域、滚轮 |
| **章节分页** | 每篇从新的一页开始，篇名落在页首，不会和上一篇的正文挤在同一页 |
| **排版设置** | 主题（纸白 / 米黄 / 青瓷 / 纯白 / 夜色）、字体（宋 / 楷 / 仿宋 / 黑 / 圆）、字号、行距、版心宽度、段间距 |
| **进度记忆** | 顶部进度条 + 竖排页码；关闭再打开自动回到上次位置（竖排精确到页，横排精确到段） |
| 其他 | 响应式（窄屏抽屉式面板）、打印样式、深色模式、无 JS 依赖的零cookie存储（仅 `localStorage`） |

快捷键：`/` 搜索 · `V` 横竖切换 · `T` 简繁 · `M` 目录 · `←`/`→` 翻页 · `j` / `k` 上下篇 · `Esc` 关闭面板

## 快速开始

```bash
git clone <repo> && cd zhuangzi-reader

# 只想要成品：构建一次
pip install -r requirements.txt
make build          # 生成 dist/zhuangzi.html
make serve          # http://127.0.0.1:8000/zhuangzi.html

# 或者直接双击 dist/zhuangzi.html
```

深链参数（便于分享阅读位置）：

```
zhuangzi.html?ci=17               # 打开第十七篇（秋水）
zhuangzi.html?mode=v              # 竖排
zhuangzi.html?script=t            # 繁体
zhuangzi.html?theme=night&fs=22   # 夜色主题、22px 字号
zhuangzi.html?q=庖丁              # 打开即搜索
zhuangzi.html?page=12             # 竖排直接翻到第 12 页
```

## 实现要点

**分页模型**：两种排版共用一套几何。#viewport 是「一页的可见区域」（版心），#book 在里面按列排布，翻页 = `translateX(页号 × 页宽)`；下一页永远在当前页左侧，所以「向右拖动」是下一页（横排竖排一致，也是传统右起书的翻法）。拖动时内容跟手（`pointerdown/move/up`），松手按位移阈值吸附到上一页/下一页。

- 横排：一列 = 一页，列宽 = 版心宽度；篇与篇之间用 `break-before: column` 强制换页，所以篇名必然在页首。
- 竖排：一列 = 一行竖排文字（宽 = 行距），一页 = 若干列；篇首用空白块（`.pgbreak`）把下一篇推到页边界。

**竖排分页细节**：正文用浏览器原生 `writing-mode: vertical-rl`，文字自然向左溢出。为了让每页正好切在栏缝上：

1. 行距微调为 `版心宽度 ÷ 整数栏数`，让「整数栏 × 栏距」等于版心宽度；
2. 栏距量化到 1/64px（浏览器的行距存储精度），否则每栏零点几像素的误差会在几百栏后累积成小半栏；
3. 篇题字号更大，行盒会被撑高，因此把篇题栏宽锁成一栏（`width: var(--pitch)`）—— 否则 33 篇下来整页会偏移小半栏，页边切在栏中间；
4. 裁切容器的宽度直接设成页边界，页边不会露出相邻页的半栏字。

（`tests/test_ui.py` 里 `test_vertical_columns_no_drift` 就是这几条不变量的回归。）

**页边裁切**：正文外层套一个与版心等宽的 `overflow: hidden` 容器（而不是靠 `clip-path`），相邻页的列在版心外就被裁掉。

**阅读位置记忆**：翻页有 280ms 过渡，量取位置必须等动画结束——随后挑「起点落在当前页、且最靠右」的段落作为锚点（`?page=` 深链与外层跳转同理，见 `tests/test_ui.py` 的回归用例）。

**简繁转换**：正体用 OpenCC `s2tw`（台标，`為/裡` 而非 `爲/裏`），再叠一层**文言文校正表**（`zreader/convert.py`）：

| 误 | 正 | 说明 |
| --- | --- | --- |
| 裡 | 里 | 里程 / 乡里，文言极少用「裡」 |
| 鹹 | 咸 | 咸 = 皆、全 |
| 鬥斛 | 斗斛 | 量器 |
| 佈施 | 布施 | 佛经旧译 |
| 覆命 | 復命 | |
| 幹越 / 鏌幹 / 幹縣令 | 干越 / 鏌干 / 干縣令 | 专名、干求 |
| 被髮而幹 | 被髮而乾 | 乾燥 |
| 雲者 / 雲至於大病 | 云者 / 云至於大病 | 曰、云云 |
| 餘愧 / 餘語 / 餘且 | 余愧 / 余語 / 余且 | 第一人称、人名 |
| 兇 / 幷 / 求儘性 | 凶 / 並 / 求盡性 | |

校正表每条规则都会在构建时**校验命中**，语料或 OpenCC 版本变化导致规则失效会直接构建失败，避免悄悄退化。

反方向（繁 → 简）逐字转换，若简化结果是 Unicode 增补区（非 BMP）的罕用字形（如 `鴳 → 𫛩`，共 15 字），则保留原字形——多数系统字体没有这些字，转换过去只会显示成豆腐块。

**全文搜索**：正文同时内嵌简、繁两版，搜索在「当前显示的那一版」上做；输入词先按显示脚本用逐字映射表归一化，所以在简体界面里输入「鯤」也能命中「鲲」。

## 语料说明

- 原文为公有领域典籍，`texts/zhuangzi.txt` 逐字节随仓库提供，构建结果可复现。
- 原文本缺少七篇篇题（刻意、田子方、知北游、徐无鬼、盗跖、渔父、列御寇），其正文被并在前一篇中；`zreader/parser.py` 按篇首句自动切分，因此目录是完整的 33 篇（267 段 / 78,339 字）。
- 语料本身存在少量脱字、讹字与括号夹注（如「奚以这九万里」「掊风」、`(上央下)`），本项目**不做校勘**，以保持语料原貌；如需精校可在 `texts/` 内替换后用 `make build` 重新生成。
